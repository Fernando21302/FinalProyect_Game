# Koinhantā 2.0

## -Descripción Breve-
Contiene las mismas mecánicas y objetivos que su [predecesor](https://github.com/JAFC-web/CODEGAME), con la diferencia de un sistema de guardado y cargado usando las letras G y C, también incluye in nivel secreto el cual se accede en el primer nivel en la plataforma frágil del borde trasero del inicio.

## -Assets-
dentro del [directorio](https://github.com/Fernando21302/FinalProyect_Game/tree/main/proyectotem) encontraras todos los assets utilizados para este juego.

## -Descripción de los scripts-
Los nuevos scripts implementados están hechos para el sistema de guardado, si quieres saber más sobre cómo funciona cada script puedes verlo en los mismo scripts ya comentados, lo encontraras en el mismo [directorio](https://github.com/Fernando21302/FinalProyect_Game/tree/main/proyectotem) en donde estan los assets.
